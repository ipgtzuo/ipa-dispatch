这次改了什么

  • 设备连接状态判定修正（本轮）：原来对 devicectl 输出做 contains("available") 子串判断，unavailable 与 disconnected 会被误判成「已连接」。现改为读取 devicectl --json-output 的 properties.connection.state 与 hardware.reality（只收录 physical 真机），用 available / connected 前缀白名单精确判定，表格输出作为回退；安装脚本同步改为按状态校验，离线设备直接报错。本页展示的是「设备在线」的完整态；真机当前没有连接设备，实际显示「未连接」、派送前检查 1/3、安装按钮禁用，见 IPA-Dispatch-设备状态修复.png。
  • 窗口控制按钮与 logo 同排（上一轮）：真机此前因系统 titlebar 占位，红黄绿灯浮在上层、自定义顶栏落在下层，logo 比交通灯低约 28px。AppKit 层补 .fullSizeContentView，SwiftUI 层让主 VStack ignoresSafeArea(.all, edges: .top)，顶栏从窗口最上沿开始；再把顶栏内容整体上移 6px，使 34px 图标与 12px 圆点垂直中心接近。真实窗口截图已验收。
  • logo 移到左边：34px 真实应用图标从右上角移到标题左侧，与「IPA Dispatch / 旁加载工坊」组成品牌区；图标移走后取消工具组右侧的细分隔线，右上角只留成对的「中」与刷新按钮。真实窗口截图已验收。
  • 收掉两处割裂留白：左栏证书列表限高、检查卡片上移紧跟证书区，内容整体顶部成组，留白改落底部；右栏「本机签名」并入标题右侧的状态胶囊（分隔线 + 锁形图标），删掉被推到底部的孤立注脚。真实窗口截图已验收。
  • 工具按钮成对、移出标题区（历史）：「中 / EN」与刷新从标题旁彻底移走，改为顶栏右侧成对工具组；两个按钮共用同一套 28px 尺寸、底色与描边（语言改为点击直接切换，去掉下拉菜单的「中⌄」箭头），消除「一个有框、一个没框」的不成对感。点上方「logo 在右（旧）」可回看当时的排布。
  • 消除主区空白：拖放区从固定 318px 改为填满剩余高度，空状态时不再有半屏留白。
  • 去掉重复信息：清单区右上角「没有 IPA」改为贴在标题旁的计数徽章，不再和右栏「0 个 IPA」重复；有内容时改为顺序说明。
  • 新增派送前检查卡：左栏下半部用设备 / 证书 / IPA 三项检查填满，并直接说明为什么「安装」是灰的。
  • 底部状态给出下一步：禁用时显示具体缺失项（添加 IPA / 连接设备 / 选有效证书），进度条只在安装中出现。
  • 状态印章改胶囊：右栏底部旋转边框的「等待」看起来像按钮，改为顶部右侧带色点的状态胶囊。
  • 可读性：UDID / SHA / 团队 ID 从 8–9pt 提到 9.5–10pt，次要文字亮度提高，长串中间截断并可悬停看全值。
  • 层级与主操作：新增卡片底色、分割线提亮；「选择 IPA 文件」升级为橙色主按钮，禁用按钮改为描边而非灰块。
  • 尺寸收紧：顶栏 64→56、底栏 78→66、左栏 230→224、右栏 344→312，最小窗口 1120×700→1040×660。
